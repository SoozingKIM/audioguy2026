# 인물 사진 드롭 폴더

여기에 새 사진을 아래 **파일명 그대로** 넣어주세요 (바꿀 사람 것만 넣으면 됩니다).
넣은 뒤 저(Claude)에게 "넣었어"라고 하면, 리사이즈·최적화해서 각 페이지의 정확한 위치에 넣어드립니다.
원본 확장자는 .jpg / .jpeg / .png / .webp 아무거나 OK (제가 .jpg로 변환).
