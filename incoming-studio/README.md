# SOUND360 Studio 캐러셀 사진 교체

이 폴더에 캐러셀에 넣을 사진을 **표시 순서대로** 넣어주세요.
다 되면 저(Claude)에게 "넣었어"라고 하면, Sanity에 업로드하고
`sound360Page.studioImages`(캐러셀 슬롯)를 새 사진들로 교체합니다.
캐러셀·인디케이터는 사진 개수에 맞춰 자동 조정됩니다.

## 파일명
- `1.jpg`, `2.jpg`, `3.jpg`, ... 순서대로 (원하는 만큼, jpg/png/webp 아무거나 → 제가 최적화)
- 넣은 개수만큼 캐러셀이 구성됩니다 (예: 5장 넣으면 5장짜리 캐러셀).

## 참고
- 현재 캐러셀은 4장(carousel-1~4)입니다. 새로 넣은 사진으로 **전체 교체**됩니다.
  (일부만 바꾸고 싶으면 알려주세요 — 그 슬롯만 교체할게요.)
- 캐러셀 이미지는 가로형(스튜디오 전경)이 잘 맞습니다.
